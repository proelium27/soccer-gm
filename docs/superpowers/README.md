# Historical plans and specs

**Nothing in this directory describes the game as it stands.** These are
one-shot working documents — a design spec and a step-by-step implementation
plan — written before a piece of work started, between 2026-07-08 and
2026-08-04. Every one of them shipped. None has been revised since it merged,
and several describe a world that has changed a great deal:

- the world was one England-only division when the earliest of these was
  written; it is 16 competitions across 8 countries now
- the transfer market, the Continental Cup and Shield, domestic and
  confederation cups, international football, manager careers and God Mode all
  arrived after most of these were filed
- constants quoted anywhere here have been retuned repeatedly

They are kept because a plan records *why* a thing was built the way it was,
and the "considered and rejected" reasoning in them is not recoverable from the
code. Read them as archaeology.

**For current state, read `CLAUDE.md`.** For the design intent that is still
live, see the docs one level up (`docs/finance-design.md`,
`docs/transfer-mobility.md`, `docs/save-performance-plan.md`).

Cross-references inside these files point at each other and at code paths that
may have moved; don't trust a line number here.
